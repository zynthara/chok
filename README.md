# chok

chok is an opinionated Go application toolkit: one strict typed config, typed
HTTP handlers with runtime OpenAPI, a gorm-backed store with owner scoping, and
batteries for identity, jobs, telemetry and cache — assembled with plain Go code.

> **Status: v3 is under development (开发中).** Nothing is released yet and the
> API may change until `v3.0.0-alpha.1`. The quickstart lives in
> [docs/quickstart.md](docs/quickstart.md).

Module path: `github.com/zynthara/chok/v3` (Go 1.27+).

## Looking for v2?

v2 is sealed on the [`v2` branch](https://github.com/zynthara/chok/tree/v2) and
receives security fixes only. Its tagged releases stay installable:

    go get github.com/zynthara/chok/v2@v2.0.0-beta.6
